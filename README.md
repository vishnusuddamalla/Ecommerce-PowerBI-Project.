# E-commerce Sales Analysis Dashboard

## Project Overview
This project analyzes e-commerce sales data using Microsoft Power BI to identify sales trends, product performance, geographical distribution, and employee-related insights.

## Tools & Technologies
- Microsoft Power BI
- DAX
- CSV datasets
- Data visualization and analysis

## Dataset
The project includes:
- FactSales
- DimDate
- DimEmployee
- DimGeography
- DimProduct

## Dashboard Objectives
- Analyze sales performance and trends.
- Evaluate product performance.
- Explore geographical sales distribution.
- Examine employee-related metrics.
- Support data-driven business decisions.

## Files Included
- `PROJECT_E-COMMERCE.pbix` — Power BI report
- CSV files — supporting datasets

## How to Use
Download the `.pbix` file and open it using Microsoft Power BI Desktop.
